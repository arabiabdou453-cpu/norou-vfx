# NOROUVFX

### Cinematic editing. Visual direction. Stories that stay.

**Norouvfx** is the professional portfolio of **Norou**, a video editor, filmmaker, VFX artist, and voice-over artist focused on turning ideas into clear, cinematic visual experiences.

## The studio

Norou works with brands, creators, and ambitious projects that need more than polished visuals. Every piece is shaped around its purpose, audience, tone, and the feeling it should leave behind.

The portfolio brings together commercial work, branded content, social campaigns, motion design, visual effects, and narrative-led video editing in one focused digital experience.

## Capabilities

| Discipline | Focus |
| --- | --- |
| Pre-production | Creative direction, planning, concepts, schedules, and production preparation |
| Video production | Commercials, branded films, and visual storytelling |
| Post-production | Editing, pacing, sound, color, finishing, and delivery |
| Motion & VFX | Motion graphics, compositing, visual effects, and polished transitions |
| Social content | Short-form edits and campaign-ready content built for attention |
| Voice-over | Voice-led storytelling that gives every piece a distinct character |

## Portfolio experience

- A cinematic showreel and selected project gallery.
- Smooth navigation between Home, Work, Services, About, and Contact.
- Responsive layouts for desktop, tablet, and mobile.
- YouTube playback with native controls, sound, fullscreen, and touch support.
- Lightweight video previews that load the player when a viewer chooses to watch.
- Keyboard-friendly controls and reduced-motion support.
- Direct WhatsApp and Instagram contact paths through the official website.

## Visual direction

The site uses a dark editorial foundation with electric violet accents, generous spacing, framed content panels, and motion-led interactions. The result is designed to feel like a focused creative reel rather than a generic portfolio template.

## Run locally

This is a static website and can be previewed with any local HTTP server.

```powershell
python -m http.server 8000
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000) in a browser.
