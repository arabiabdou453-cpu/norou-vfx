## ✦ The experience

Norouvfx is the creative portfolio of **Norou** — a video editor, filmmaker, VFX artist and voice-over artist. The site is built around one idea: make every frame carry a feeling.

From the first showreel frame to the final contact action, the experience combines a dark editorial canvas, electric violet accents, cinematic motion and carefully paced content presentation.

## 🚀 Run locally

This is a lightweight static website. Start a local server from the project folder:

```powershell
python -m http.server 8000
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000) in your browser.
