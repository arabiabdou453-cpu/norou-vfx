# Inline YouTube Player Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Play all six YouTube videos inside their existing portfolio cards with native controls, full-button click targets, single-player enforcement, and responsive mobile behavior.

**Architecture:** Remove the custom modal and make each generated card own an optional inline player layer. A single module-level active-player record guarantees that opening one card destroys any prior iframe. The existing Framer iframe guard remains responsible for preventing YouTube requests before an explicit user action.

**Tech Stack:** Static HTML, CSS, vanilla JavaScript, PowerShell regression checks, Chrome DevTools.

## Global Constraints

- Preserve every card's current dimensions on desktop and mobile.
- Load no YouTube iframe before a deliberate play-button action.
- Keep at most one active YouTube iframe.
- Apply the behavior to all six configured video IDs.
- Use native YouTube controls and native iframe fullscreen.
- Keep the rest of the Framer page visually unchanged.

```powershell
'No custom modal player remains' = $playerScript -notmatch 'norou-player__dialog|requestFullscreen|aria-modal'
'Inline player host is installed' = $playerScript -match 'norou-inline-player' -and $playerStyle -match '\.norou-inline-player'

'Full YouTube button is the click target' = $playerScript -match 'play\.addEventListener\("click"' -and $playerStyle -match 'touch-action:\s*manipulation'
'Mobile close target is accessible' = $playerStyle -match 'min-width:\s*44px' -and $playerStyle -match 'min-height:\s*44px'
```

### Task 2: Replace the modal with one inline active player

**Files:**
- Modify: `assets/norou-player.js`

**Interfaces:**
- Produces: `openInlinePlayer(video, card, trigger)` and `closeActivePlayer(restoreFocus)` behavior.
- Maintains: `activePlayer` as either `null` or `{ card, trigger, layer }`.

- [ ] **Step 1: Remove modal creation and modal-only controls**

Delete the fixed player, dialog, header, previous/next/fullscreen buttons, body scroll lock, and modal keyboard navigation.

- [ ] **Step 2: Add minimal inline lifecycle**

Create an active layer with this structure:

```html
<div class="norou-inline-player">
  <iframe data-norou-player-active="true" allowfullscreen></iframe>
  <button class="norou-inline-player__close" type="button" aria-label="Close video">×</button>
</div>
```

Set the iframe source only after the play action:

```text
https://www.youtube-nocookie.com/embed/{id}?autoplay=1&controls=1&fs=1&playsinline=1&rel=0
```

- [ ] **Step 3: Enforce exactly one active iframe**

Before opening a card, call `closeActivePlayer(false)`. On close, visibility change, and page hide, remove the active layer so playback and audio stop immediately.

- [ ] **Step 4: Keep the complete red icon as the action**

Attach the handler to the button itself and stop propagation inside the handler. Keep the triangle decorative so the entire red rectangle has one action target.

- [ ] **Step 5: Run JavaScript syntax validation**

Run: `node --check .\assets\norou-player.js`

Expected: exit code 0 and no output.
